# Lesson 1 Lab — Explore the Azure Portal

## 🎯 Objective

The goal of this lab is to become familiar with the Azure Portal before creating any Azure resources.

By the end of this lab, you should be comfortable navigating the Azure Portal and locating common Azure services.

---

## ⏱ Estimated Time

**10–15 minutes**

---

## 📋 Prerequisites

- An internet connection
- A Microsoft account
- An Azure Free Account (if you don't already have one)

Create a free Azure account here:

https://azure.microsoft.com/free/

Open the Azure Portal:

https://portal.azure.com

---

# Step 1 — Sign in to Azure

Sign in to the Azure Portal using your Microsoft account.

Once you're signed in, spend a minute looking around before clicking anything.

Notice the different sections available on the Home page.

---

# Step 2 — Explore the Home Page

The Home page is your starting point for managing everything in Azure.

Take a few minutes to locate the following:

- 🔍 Search Bar
- ⭐ Favorites
- 📢 Notifications
- ☁️ Cloud Shell
- ⚙️ Portal Settings
- ➕ Create a Resource

Don't worry if you don't understand what each one does yet.

The goal is simply to become familiar with where everything is located.

---

# Step 3 — Locate Your Subscription

Use the search bar at the top of the portal.

Search for:

> **Subscriptions**

Open your subscription.

Look around and locate:

- Subscription Name
- Subscription ID
- Cost Management
- Access Control (IAM)
- Resource Groups

Do **not** make any changes.

Just become familiar with what information is available.

---

# Step 4 — Explore Resource Groups

Return to the search bar.

Search for:

> **Resource Groups**

Open the Resource Groups page.

Notice:

- Existing Resource Groups (if any)
- Location
- Tags
- Activity
- Resources inside each group

If your account is brand new, this page may be empty.

That's perfectly normal.

Later in the course, you'll create your own Resource Groups.

---

# Step 5 — Browse Virtual Machines

Search for:

> **Virtual Machines**

Open the Virtual Machines page.

Take a look around.

Notice:

- The **Create** button
- Virtual Machine list
- Filters
- Monitoring options

If no Virtual Machines exist yet, that's expected.

You will create one later in this course.

---

# Step 6 — Practice Using Search

Use the Azure search bar to locate the following services:

- Storage Accounts
- Virtual Networks
- App Services
- Azure Monitor
- Microsoft Entra ID

Don't open every setting.

Simply practice finding services using search.

This is one of the fastest ways to navigate Azure.

---

# 💡 Tip

You do **not** need to memorize where every service is located.

Even experienced Azure administrators primarily use the search bar to quickly find resources.

---

# 🎯 Lab Complete!

Congratulations!

You have successfully explored the Azure Portal without creating any resources.

---

Before moving on, see if you can answer these questions without looking back.

- Where do you find your Azure Subscription?
- What is a Resource Group?
- Can you locate the Virtual Machines page?
- Where is the Azure search bar?
- Why is the search bar one of the most useful navigation tools?
