# John Savill's Technical Training --- AZ-900 Video Resource

John Savill's Technical Training is used throughout this AZ-900 course
as a **supplemental video resource**.

The lesson pages link to individual John Savill videos when a visual
explanation can help reinforce the Microsoft Learn material.

> \[!IMPORTANT\] The videos are supplemental study resources. Always use
> the current Microsoft AZ-900 study guide as the source of truth for
> the skills currently measured on the exam.

------------------------------------------------------------------------

# 🎥 Why These Videos Are Included

John Savill's Azure training is especially useful for:

-   Visual learners.
-   Seeing Azure concepts explained on a whiteboard.
-   Reinforcing material after reading Microsoft Learn.
-   Understanding how similar Azure services differ.
-   Reviewing difficult topics before moving to the next lesson.
-   Final review before the AZ-900 exam.

A useful study pattern is:

``` text
Microsoft Learn
      ↓
Course Lesson
      ↓
John Savill Video
      ↓
Hands-On Lab
      ↓
Knowledge Review
```

You do not need to memorize everything said in every video.

Focus on the concepts that match the current AZ-900 objectives.

# 🎓 How to Use the Videos With This Course

## First Time Learning a Topic

Use this order:

``` text
1. Read the lesson objective
        ↓
2. Complete the Microsoft Learn material
        ↓
3. Read the lesson notes
        ↓
4. Watch the recommended John Savill video
        ↓
5. Complete the lab when one is provided
        ↓
6. Complete the lesson review
```

The video should reinforce what you have already started learning.

------------------------------------------------------------------------

## When a Topic Is Confusing

If two Azure concepts feel similar:

``` text
READ
  ↓
WATCH
  ↓
COMPARE
  ↓
EXPLAIN IT YOURSELF
```

After watching the video, try explaining the difference without looking
at your notes.

For example:

``` text
Azure Monitor
vs.
Azure Advisor
vs.
Azure Service Health
```

If you can explain the main job of each service, you are more likely to
recognize the correct service in an exam scenario.

------------------------------------------------------------------------

## Before the Exam

A useful final-review order is:

``` text
comparison-table.md
        ↓
cram-sheet.md
        ↓
exam-tips.md
        ↓
John Savill Study Cram
        ↓
Microsoft Practice Assessment
```

When you find a weak area, return to the appropriate lesson instead of
trying to memorize the answer.

------------------------------------------------------------------------

# ⚠️ Keep Exam Objectives Current

Certification exams change over time.

Older videos may still explain Azure concepts correctly while covering
topics that are no longer emphasized on the current exam, or they may
use older product names.

For example, Microsoft renamed:

``` text
Azure Active Directory
        ↓
Microsoft Entra ID
```

When a video and the current Microsoft study guide appear different:

> **Follow the current Microsoft AZ-900 study guide for what you need to
> know for the exam.**

### Current AZ-900 Study Guide

https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900
