# Microsoft Learn --- AZ-900 Learning Resource

Microsoft Learn is the **primary official learning resource** used
throughout this AZ-900 training course.

The lessons in this repository organize and reinforce the material,
while Microsoft Learn provides the current Microsoft documentation,
training modules, assessments, and certification guidance.

> \[!IMPORTANT\] Azure services and certification objectives can change
> over time. Use the current Microsoft AZ-900 Study Guide as the
> **source of truth** for what is measured on the exam.

------------------------------------------------------------------------

# 🎓 AZ-900 --- Microsoft Azure Fundamentals

The **Microsoft Certified: Azure Fundamentals** certification is
designed to demonstrate foundational knowledge of cloud concepts and
Microsoft Azure.

### Official Certification Page

https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/

Microsoft currently organizes the core AZ-900 exam content into three
major areas:

``` text
AZ-900
  |
  +-- Describe Cloud Concepts
  |
  +-- Describe Azure Architecture and Services
  |
  +-- Describe Azure Management and Governance
```

These areas are the foundation for the lessons in this repository.

# 🔎 How to Read Microsoft Learn Effectively

Avoid reading a module from beginning to end without stopping to think
about it.

After each major concept, ask yourself:

``` text
WHAT IS IT?

WHAT DOES IT DO?

WHEN WOULD I USE IT?

WHAT IS IT EASILY CONFUSED WITH?
```

For example:

``` text
Azure Advisor

What is it?
→ Recommendation service

What does it do?
→ Suggests improvements

When would I use it?
→ When looking for ways to improve Azure resources

What is it confused with?
→ Azure Monitor

Difference?
→ Monitor observes
→ Advisor recommends
```

This approach is more useful for AZ-900 than memorizing paragraphs.

# ⚠️ Watch for Changed Product Names

Azure changes over time.

Microsoft Learn is useful because Microsoft's current documentation
normally reflects current terminology.

For example:

``` text
Azure Active Directory
        ↓
Microsoft Entra ID
```

Older videos, screenshots, articles, or practice questions may still use
previous names.

When you encounter different terminology:

1.  Check the current Microsoft Learn documentation.
2.  Learn the current name.
3.  Recognize the older name in case you encounter older study material.

# 📊 Practice Assessment Strategy

Do not focus only on your score.

Track your weak areas.

Example:

  Topic                       Result   Action
  --------------------------- -------- --------------------------
  Cloud Models                Strong   Quick review
  Azure Storage               Weak     Return to storage lesson
  Azure RBAC                  Strong   Quick review
  Azure Monitor vs. Advisor   Weak     Review comparison table
  Pricing                     Weak     Review cost lesson

Then repeat:

``` text
ASSESS
   ↓
FIND WEAKNESS
   ↓
REVIEW
   ↓
RETEST
```
